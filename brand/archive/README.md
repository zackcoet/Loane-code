# The outline mark — retired October 2026

Two hairline rings with L O A N E spaced across them. Replaced by the
two filled circles overlapping in butter (`../logo-flat.svg`).

Kept rather than deleted because these are the files every screenshot,
deck and TestFlight build before October 2026 was made with, and
because `generate-icons.py` is where the old icon geometry was measured
off the brand deck — if we ever need to know what the previous tile
actually was, it is written down here.

Nothing in the app reads from this folder. `brand/generate-brand.py`
replaced `generate-icons.py` and writes the current icons.
